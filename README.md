# Продажа цифровых книг

Лабораторная работа № 1 по прикладному программированию.

Тема: «ООП в Python. Обработка исключительных ситуаций. Форматы XML и JSON».

Вариант 3: продажа цифровых книг.

## Цель работы

Разработать программу на Python для продажи цифровых книг, используя объектно-ориентированное программирование, обработку исключений и хранение данных в форматах JSON и XML.

## Планируемые возможности

- Добавление, просмотр, изменение и удаление записей каталога.
- Поиск цифровых книг.
- Работа с авторами, издательствами и категориями.
- Добавление книг в корзину и удаление из неё.
- Оформление заказа и учебная имитация оплаты.
- Учёт доступа покупателя к приобретённым книгам.
- Сохранение и загрузка данных в форматах JSON и XML.
- Обработка ошибок ввода и работы с файлами.

## Планируемые классы

1. User — пользователь.
2. Customer — покупатель.
3. Author — автор.
4. Publisher — издательство.
5. Category — категория.
6. DigitalBook — цифровая книга.
7. Cart — корзина.
8. CartItem — позиция корзины.
9. Order — заказ.
10. OrderItem — позиция заказа.
11. Payment — учебная оплата.
12. PurchaseLicense — право доступа к купленной книге.

## Этапы выполнения

1. Проектирование диаграммы классов UML.
2. Реализация классов и операций с данными.
3. Создание консольного интерфейса.
4. Обработка стандартных и собственного исключений.
5. Реализация сохранения и загрузки JSON и XML.
6. Проверка программы и актуализация диаграммы.
7. Подготовка отчёта.

Определены предметная область, планируемые возможности и предварительный состав классов. Реализация программы ещё не добавлена.
