# Продажа цифровых книг

Лабораторная работа № 1 по прикладному программированию.

Тема: «ООП в Python. Обработка исключительных ситуаций.
Форматы XML и JSON».

Вариант 3: продажа цифровых книг.

## Назначение

Консольная программа для управления каталогом цифровых книг,
работы с корзиной, оформления заказов и учебной имитации оплаты.

## Возможности

- Создание, просмотр, изменение и удаление книг каталога.
- Поиск по части названия без учёта регистра.
- Работа с корзиной и подсчёт стоимости.
- Оформление заказа с сохранением цены и названия на момент покупки.
- Учебная имитация успешной и неуспешной оплаты.
- Выдача прав доступа после успешной оплаты.
- Защита от повторного приобретения книги.
- Сохранение и восстановление состояния в JSON.
- Экспорт и загрузка состояния в XML.
- Обработка ошибок ввода, операций и файлов.

Консольный интерфейс работает с одним покупателем.
Оплата имитируется: платёжные сервисы не подключены.
Путь к приобретённой книге отображается без скачивания файла.

## Требования

- Python 3.13.
- Дополнительные библиотеки не требуются.
- Проверенная среда разработки: PyCharm 2026.1.3.

## Запуск в Windows PowerShell

Из папки проекта:

```powershell
.\.venv\Scripts\python.exe main.py
```

Также можно открыть main.py в PyCharm и выбрать Run 'main'.

## Работа с данными

Основное сохранение: data/shop_state.json.

При первом запуске без сохранения создаются покупатель
и две книги начального каталога.

При последующих запусках загружается сохранённое состояние.

- Пункт 15: сохранить JSON.
- Пункт 16: загрузить JSON.
- Пункт 17: экспортировать data/shop_state.xml.
- Пункт 18: загрузить XML.
- Пункт 0: сохранить JSON и завершить программу.

После загрузки XML состояние можно сохранить в JSON
через пункт 15 или при выходе через пункт 0.

При ошибке чтения существующего сохранения программа
сообщает об ошибке и не заменяет файл начальным каталогом.

Запись выполняется через временный файл с последующей заменой
основного файла после успешной записи.

## Форматы хранения

JSON содержит каталог, покупателей, корзины, заказы,
платежи и права доступа.

Связи сохраняются через идентификаторы.
Денежные значения записываются строками и восстанавливаются
как Decimal.

XML представляет те же данные в виде вложенных элементов.
Атрибут type указывает тип значения: object, array,
integer или string.

Коллекция приобретённых книг восстанавливается по правам доступа.
После загрузки нумерация новых записей продолжается.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_project
```

Проверяются сохранение старой цены заказа, повторная покупка,
повторная попытка оплаты, восстановление JSON и XML,
ошибочные файлы и продолжение работы меню после ошибок.
